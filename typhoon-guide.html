태풍 경로와 수치를 읽는 방법

태풍 지도에서 가장 눈에 띄는 것은 중심선이지만, 중심선만으로 위험을 판단하면 안 됩니다. 중심기압, 최대풍속, 강풍반경, 폭풍반경, 이동속도, 특보를 함께 확인해야 실제 생활 위험을 더 잘 가늠할 수 있습니다. 이 페이지는 현재 태풍 화면의 수치를 읽는 순서를 정리한 안내서입니다.

1. 태풍 경로는 어떻게 읽나요?

지도에서 실선이나 연결선으로 표시되는 경로는 태풍 중심의 과거 분석 위치와 앞으로의 예측 위치를 이어 놓은 것입니다. 현재 분석 위치와 예측 위치를 먼저 구분하고, 예측 시각이 멀어질수록 불확실성이 커진다는 점을 기억해야 합니다.

예측 중심선은 피해가 발생하는 경계선이 아닙니다. 중심이 우리 지역을 지나지 않아도 강풍반경이나 폭풍반경에 들어갈 수 있고, 태풍의 오른쪽·왼쪽, 지형, 전선과의 상호작용에 따라 비와 바람의 분포가 달라질 수 있습니다. 기상청 상세정보의 70% 확률반경은 중심 위치 예측의 불확실성을 설명하는 자료이므로, 중심선과 함께 확인하는 것이 좋습니다.

읽는 순서: 현재 위치 확인 → 우리 지역과의 거리 확인 → 강풍·폭풍반경 확인 → 예상 시각 확인 → 기상특보와 재난문자 확인

2. 중심기압과 최대풍속

중심기압(hPa)은 태풍 중심의 기압입니다. 일반적으로 중심기압이 낮을수록 강한 태풍일 가능성이 있지만, 중심기압 하나만으로 피해를 단정할 수는 없습니다. 같은 기압이라도 태풍의 크기, 이동속도, 상륙 지점, 주변 기압배치에 따라 영향이 달라집니다.

최대풍속(m/s 또는 km/h)은 태풍 중심 부근의 최대풍속입니다. 숫자가 높을수록 시설물과 나무, 선박, 간판에 작용하는 바람의 위험이 커집니다. 화면의 m/s 값을 km/h로 대략 환산하려면 3.6을 곱하면 되지만, 기관별 측정 기준과 평균 시간은 다를 수 있으므로 출처의 단위를 그대로 비교하세요.

표시 항목무엇을 뜻하나요?생활 속에서 볼 점
중심기압태풍 중심의 기압낮아지는지, 높아지는지 변화 추세를 봅니다.
최대풍속중심 부근의 가장 강한 바람외부 시설물, 해안, 선박, 이동 가능성을 판단합니다.
이동속도태풍 중심이 이동하는 속도빠르면 대비 시간이 짧아질 수 있습니다.
강풍반경초속 15m 이상 바람이 부는 반경중심선이 비껴가도 반경 안인지 확인합니다.
폭풍반경초속 25m 이상 바람이 부는 반경매우 강한 바람이 예상되는 범위입니다.

기상청은 2026년부터 태풍 강도를 숫자 체계로 제공하고 있습니다. 강도 숫자나 기준은 정책 변경이 있을 수 있으므로, 실제 판단에서는 기상청 태풍의 분류의 최신 기준을 확인하세요.

3. 태풍과 열대저기압은 무엇이 다른가요?

열대저기압은 따뜻한 바다에서 발달하는 저기압성 순환을 넓게 부르는 말입니다. 우리나라와 일본의 기준에서는 중심 부근 최대풍속이 초속 17m 미만이면 열대저압부(TD), 초속 17m 이상이면 태풍으로 분류합니다. 따라서 열대저압부라고 해서 영향이 없다는 뜻은 아닙니다. 비구름과 돌풍, 풍랑은 강도와 별개로 발생할 수 있습니다.

구분최대풍속 기준확인할 내용
열대저압부17m/s 미만발달 여부와 예상 경로, 비·풍랑 자료를 확인합니다.
태풍17m/s 이상강도, 반경, 특보, 상륙·근접 시각을 함께 봅니다.

4. 태풍은 발생해서 어떻게 소멸하나요?

태풍은 보통 따뜻한 해수면에서 수증기를 공급받으며 발달합니다. 처음에는 대류가 흩어진 열대요란으로 시작하고, 저기압성 순환이 정리되면서 열대저압부가 됩니다. 중심 부근의 바람이 기준을 넘으면 태풍으로 분류됩니다.

  1. 열대요란: 따뜻한 바다와 수증기, 대기 불안정이 모여 비구름이 조직되기 시작합니다.
  2. 열대저압부: 순환이 뚜렷해지고 중심 위치와 강도 추적이 시작됩니다.
  3. 태풍 발달: 해수면에서 공급되는 에너지가 충분하면 중심기압이 낮아지고 바람이 강해집니다.
  4. 최성기와 이동: 바다 위에서는 강도가 유지되거나 변동하며, 주변 기압배치에 따라 방향과 속도가 달라집니다.
  5. 약화와 소멸: 차가운 바다, 육지 마찰, 건조한 공기, 강한 연직시어를 만나면 약해지고 온대저기압으로 변하거나 소멸할 수 있습니다.

태풍이 약해졌다는 것은 모든 위험이 사라졌다는 뜻이 아닙니다. 육지에 상륙한 뒤에도 폭우, 하천 범람, 산사태, 파도와 강풍이 계속될 수 있으므로 공식 특보가 해제될 때까지 주의해야 합니다.

5. 기상특보는 태풍 지도와 어떻게 함께 보나요?

태풍 지도는 위치와 예상 경로를 이해하는 도구이고, 기상특보는 특정 지역에서 재해가 발생할 가능성을 경고하는 공식 판단입니다. 두 정보가 다르게 보일 때는 기상특보와 재난문자를 우선해야 합니다.

  • 태풍특보와 함께 강풍, 호우, 풍랑, 폭풍해일 특보가 발효됐는지 확인합니다.
  • 내가 있는 시·군·구와 이동 예정 경로가 특보 구역에 포함되는지 봅니다.
  • 특보가 없더라도 하천변, 해안가, 지하차도, 산지처럼 장소 자체가 위험하면 접근하지 않습니다.
  • 학교·교통·대피 결정은 지도 중심선이 아니라 기상청, 행정안전부, 지자체의 최신 안내를 따릅니다.

기상청 현재 특보 확인

6. 자료 출처와 업데이트 주기

이 사이트는 기관별 자료를 한 화면에서 보기 쉽게 정리한 보조 도구입니다. 전세계 현재 태풍은 GDACS 자료를 바탕으로 약 5분마다 다시 확인하고, 지역별 현재 날씨는 Open-Meteo의 현재 조건 자료를 약 10분마다 다시 확인합니다. 기상청 태풍정보는 KMA API 인증키가 설정된 경우 기상청의 최신 발표를 요청합니다.

자료가 없을 때는 예시 태풍을 실제 위치처럼 표시하지 않습니다. 통신 지연, 기관별 발표 시각 차이, API 장애로 화면이 늦게 갱신될 수 있으므로 카드에 표시된 확인 시각을 함께 확인하세요. 긴급 판단은 반드시 기상청 날씨누리 태풍정보와 재난문자를 기준으로 해야 합니다.

  • 기상청 태풍의 분류: 강도, 강풍반경, 폭풍반경 설명
  • 기상청 태풍 상세정보 도움말: 경로와 확률반경 해설
  • 기상청 태풍 국민행동요령: 공식 행동요령
  • Open-Meteo 문서: 현재 날씨 조건과 단위
  • GDACS: 전세계 재난·열대저기압 참고 자료

업데이트 기준: 2026년 7월 18일 작성. 특보 기준, API 제공 방식, 기관 서비스 화면은 변경될 수 있으므로 실제 상황에서는 연결된 공식 출처를 다시 확인합니다.
