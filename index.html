분석 위치

현재 또는 기준시각의 태풍 중심 위치입니다. 지도에서는 붉은 마커로 표시됩니다.

예측 경로

미래 예측 지점을 연결한 선입니다. 선이 우리 지역을 비껴가도 강풍반경 안이면 대비가 필요합니다.

중심기압

중심기압이 낮을수록 강한 태풍일 가능성이 큽니다. 피해는 이동속도, 반경, 지형과 함께 판단해야 합니다.

최대풍속

초속 15m 이상은 강풍반경, 25m 이상은 폭풍반경 판단에 연결됩니다.

한반도 영향

목록 API의 상륙, 직접영향, 간접영향, 영향 없음 분류로 우리나라 영향 정도를 빠르게 구분할 수 있습니다.

FAQ

자주 묻는 질문

태풍목록과 태풍정보 API는 어떻게 다른가요?

태풍목록 API는 연도별 태풍 이름과 기간을 보여주고, 태풍정보+예측 API는 기준시각의 좌표, 중심기압, 최대풍속, 반경을 보여줍니다.

이 지도는 공식 예보인가요?

공식 예보 원문은 기상청입니다. 이 사이트는 API 자료를 시각화해 이해를 돕는 보조 화면입니다.

한글 지명은 어떻게 표시되나요?

기본 지도 위에 태풍 확인에 자주 필요한 주요 지명을 한국어 레이어로 추가했습니다.

API 키가 공개되나요?

아니요. Cloudflare Pages Function이 서버 측에서 `KMA_AUTH_KEY`를 읽고, 브라우저에는 가공된 JSON만 전달합니다.
