API Connection

API 정보와 연결 상태

아래 상태값은 Cloudflare Pages Function의 `/api/health` 응답으로 확인합니다. 정상 배포와 `KMA_AUTH_KEY` 환경변수가 설정되어 있으면 기상청 API Hub 자료가 실제 JSON으로 표시됩니다.

API 연결 상태를 확인하는 중입니다.
상태 점검

/api/health

Cloudflare Function 실행 여부, 기상청 API 키 설정 여부, 기상청 API 연결 가능 여부를 확인합니다.

표시 항목: cloudflareFunction, kmaAuthKey, kmaReachable, kmaNormalService

국내 영향 태풍

/api/korea-typhoons

우리나라에 영향을 준 태풍을 연도별로 조회합니다. 상륙, 직접영향, 간접영향, 영향 없음으로 구분합니다.

예시: 2016년 말라카스, 차바

연도별 태풍목록

/api/typhoon-list

기상청 태풍목록 API에서 태풍번호, 이름, 진행상태, 영향분류, 시작·종료 시각을 가져옵니다.

예시: /api/typhoon-list?YY=2012

상세 예측

/api/typhoon-detail

연도, 태풍번호, 발표번호 기준으로 분석 위치와 예측 경로를 지도와 표에 표시합니다.

예시: /api/typhoon-detail?YY=2011&typ=9&seq=8&mode=1

시점 기준 예측

/api/typhoon

특정 시각 기준의 태풍정보+예측 자료를 가져옵니다. 기준시각이 없으면 API 응답 상태에 따라 최신 또는 예시 자료가 표시됩니다.

예시: /api/typhoon?tm=201108070100&mode=1

표시 방식

지도 · 카드 · 표

API 응답은 중심기압, 최대풍속, 이동방향, 강풍반경, 확률반경, 위치 설명으로 나뉘어 화면에 표시됩니다.

오류 시: 예시 자료와 오류 메시지를 함께 표시합니다.

발표번호 seq

같은 태풍도 발표번호에 따라 분석 위치와 예측 경로가 달라집니다. 특정 발표 시점의 예보를 비교할 때 사용합니다.

중심기압

중심기압이 낮을수록 강한 태풍일 가능성이 큽니다. 피해는 이동속도, 반경, 지형과 함께 판단해야 합니다.

최대풍속

초속 15m 이상은 강풍반경, 25m 이상은 폭풍반경 판단에 연결됩니다.

FAQ

자주 묻는 질문

국내 영향 태풍 API는 무엇을 보여주나요?

연도별 태풍 중 한반도 영향 분류, 최저 중심기압, 최대풍속, 발생 기간을 보여줍니다.

typ_data API는 언제 쓰나요?

특정 연도, 태풍번호, 발표번호의 분석·예측을 확인할 때 씁니다.

API 키가 공개되나요?

아니요. Cloudflare Pages Function이 서버 측에서 `KMA_AUTH_KEY`를 읽고, 브라우저에는 가공된 JSON만 전달합니다.
