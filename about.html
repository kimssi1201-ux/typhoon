소개

Typhoon Route Korea는 태풍 경로, 국내 영향 여부, 예측 발표 자료, 행동요령을 한 화면에서 확인할 수 있도록 만든 생활 기상 정보 웹사이트입니다. 태풍이 접근할 때 사용자가 가장 먼저 궁금해하는 질문은 “어디로 오고 있는가”, “우리 지역에 영향을 주는가”, “지금 무엇을 준비해야 하는가”입니다. 이 사이트는 그 질문에 맞춰 지도, 표, 카드, 체크리스트 형태로 정보를 정리합니다.

운영 목적

태풍 정보는 공식 발표 시각과 예보 갱신에 따라 계속 바뀝니다. 중심선만 보면 위험을 작게 판단할 수 있기 때문에, 본 사이트는 중심 위치와 예상 경로뿐 아니라 중심기압, 최대풍속, 강풍반경, 국내 영향 분류를 함께 보여주는 방향으로 구성되어 있습니다.

데이터 처리 방식

기상청 API Hub의 공개 API를 Cloudflare Pages Function에서 호출하고, 브라우저에는 필요한 JSON 정보만 전달합니다. API 인증키는 브라우저에 노출하지 않고 서버 환경변수로 관리합니다. 지도 배경은 OpenStreetMap 타일을 사용하고, 주요 도시와 해역명은 별도의 한글 라벨로 보완합니다.

공식 발표 우선 원칙

이 사이트는 정보 접근성을 높이기 위한 보조 도구이며, 기상청 특보, 행정안전부와 지자체의 재난 안내, 재난문자를 대체하지 않습니다. 실제 대피, 선박 운항, 학교 운영, 시설 통제 판단은 반드시 공식 기관의 최신 발표를 기준으로 해야 합니다.

콘텐츠 원칙

  • 타 사이트 화면을 복제하지 않고 자체 UI로 구성합니다.
  • 출처를 명확히 밝히고 공식 자료 링크를 제공합니다.
  • 재난 상황에서 오해를 줄 수 있는 확정적 표현을 피합니다.
  • 사용자가 모바일에서도 핵심 정보를 빠르게 확인할 수 있도록 개선합니다.
