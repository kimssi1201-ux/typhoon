소개

Typhoon Route Korea는 태풍 경로와 예측 정보를 쉽게 확인할 수 있도록 만든 생활 기상 정보 웹사이트입니다.

기상청 API Hub 자료를 Cloudflare Function에서 받아와 브라우저에는 필요한 정보만 표시하며, API 인증키는 서버 환경변수로 보호합니다.

운영 원칙

  • 기상청과 공식 기관 발표를 우선합니다.
  • 태풍 경로는 중심선이 아니라 반경과 특보까지 함께 안내합니다.
  • 재난 상황에서는 지자체와 정부 안내를 최우선으로 안내합니다.
