데이터 출처와 이용 안내

Typhoon Route Korea는 태풍 정보를 사용자가 이해하기 쉬운 형태로 재구성하는 보조 정보 사이트입니다. 화면에 표시되는 경로, 표, 국내 영향 분류는 공식 발표 자료를 기반으로 가공되며, 원자료의 갱신 시각과 API 응답 상태에 따라 표시 결과가 달라질 수 있습니다.

주요 출처

  • 기상청 API Hub: 태풍목록, 우리나라 영향 태풍, 태풍정보+예측 자료
  • 기상청 태풍정보: 공식 태풍 통보문과 경로 확인
  • OpenStreetMap: 지도 배경 타일
  • 국민재난안전포털: 재난 행동요령 참고
  • 일본 기상청 JMA: 북서태평양 열대저기압 보조 참고

자료 해석 시 주의사항

태풍 예측은 시간이 지날수록 바뀔 수 있습니다. 예상 경로 중심선은 태풍 중심이 이동할 가능성이 높은 선일 뿐이며, 강풍과 폭우는 중심선 밖에서도 발생할 수 있습니다. 특히 강풍반경, 폭풍반경, 70% 확률반경, 호우 특보, 풍랑 특보를 함께 확인해야 실제 위험을 판단할 수 있습니다.

실시간성 안내

사이트는 API를 주기적으로 호출해 최신 응답을 표시하도록 설계되어 있지만, 통신 장애, API 제한, 원자료 갱신 지연, 브라우저 캐시 상태에 따라 표시가 늦어질 수 있습니다. 중요한 의사결정에는 반드시 기상청 공식 화면과 지자체 공지를 함께 확인하세요.

저작권과 표시 원칙

타 기상 서비스의 화면을 복제하지 않고, 자체 UI와 자체 설명문으로 구성합니다. 외부 자료는 출처를 밝히고 링크로 연결하며, 필요한 범위에서만 정보 확인용으로 사용합니다.

면책

본 사이트의 정보는 재난 대응을 돕기 위한 참고 자료입니다. 대피, 운항, 등하교, 시설 통제, 행사 취소 같은 결정은 공식 기관의 최신 발표와 현장 안전 책임자의 판단을 따라야 합니다.
